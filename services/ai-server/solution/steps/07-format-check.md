# Step 7: 结构与格式自检

## 目标

落盘前逐项核对结构与格式，防漏节、防语法错。

## 结构自检

题解须含以下标题，缺一不可（`总结` 可省）：

| 层级 | 标题 |
|------|------|
| H1 | `# 题目编号 题目名称` |
| H2 | `## 题目描述` |
| H2 | `## 输入格式` |
| H2 | `## 输出格式` |
| H2 | `## 输入输出样例` |
| H2 | `## 数据范围` |
| H2 | `## 算法分析` |
| H3 | `### 问题建模`（内含数据范围与分档表） |
| H3 | `### 算法演进`（内含阶梯总览表 + 各档 `#### 档位 k`） |
| H3 | `### 状态定义与转移`（条件必出；非 DP/图论/数据结构题可省，须在演进内注明原因） |
| H3 | `### 算法步骤` |
| H2 | `## 代码实现` |
| H3 | `### 暴力参照版`（若档位 1 即暴力，则与版本 1 合并） |
| H3 | `### 版本 1｜档位 1：…` |
| H3 | `### 版本 k｜档位 k：…`（k = 2..N-1，可多段） |
| H3 | `### 版本 N｜档位 N：满分解` |
| H2 | `## 复杂度分析` |
| H3 | `### 时间复杂度` |
| H3 | `### 空间复杂度` |
| H2 | `## 边界情况与易错点` |
| H2 | `## 总结`（可选） |

```bash
F={输出目录}/{题目编号}_{题目名称}.md
grep -n '^#\{1,3\} ' "$F"        # 对照上表核对标题
grep -c '^### 版本 ' "$F"        # 版本数应 = step 4 的档位数 N
grep -c '^#### 档位 ' "$F"       # 档位小节数亦应 = N
```

对照上表核对。两个计数不等 → 回 step 4 / step 5 对齐编号。

## LaTeX / Markdown 规范

| 项 | 正 | 误 |
|----|----|----|
| 数组下标 | `$a_i$` | `a[i]`、`a\_i` |
| 区间 | `$[L, R]$` | `\[L, R]` |
| 行内公式 | `$n \le 10^5$` | 裸写 `n<=10^5` |
| 行间公式 | `$$dp_i = \dots$$` | 混入正文 |
| 代码块 | ` ```cpp ` | ` ```c++ `、无语言标签 |

- 所有变量、数字、公式**必**用 LaTeX
- 代码块统一 `cpp` 高亮

## 内容自检

1. 正文 ≥ 200 行（竞赛级深度）
2. 算法演进为**分档阶梯**：≥ 2 档，含特殊性质档或最小范围档，每档有复杂度与可拿分
3. 「问题建模」的数据范围表、「算法演进」档位、「代码实现」版本三者编号对齐
4. 代码版本与档位一一对齐，满分解过全部样例，极端规模经运算量估算不超时限
5. 复杂度分析含**各档复杂度汇总表**，满分解推导与数据范围自洽（不会 TLE / MLE）
6. 易错点含各档特有陷阱，并贴合本题，非泛泛而谈
7. 样例、图片、公式、表格与原题一致
8. 非中文原题：译文贴合场景、术语统一、限定词与原文等价，通读无逻辑错

## 数值校验

```bash
F={输出目录}/{题目编号}_{题目名称}.md
grep -c '^### 版本 ' "$F"     # = 档位数 N
grep -c '^#### 档位 ' "$F"    # = 档位数 N
```

两数应相等；不等则回 step 4 / 5 对齐。
