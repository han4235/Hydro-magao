# Step 5: 写代码实现

## 目标

写 `## 代码实现` 段。**按 step 4 的档位逐档给一版代码**，每版都是完整、可直接提交、能在该档数据上 AC 的程序。

## 结构（强规则）

```
## 代码实现

### 暴力参照版
（朴素实现；不计分，供理解）

### 版本 1｜档位 1：<该档简述，如「链的特殊性质」>
### 版本 2｜档位 2：<简述>
...
### 版本 N｜档位 N：满分解
```

规则：

1. **版本数 = step 4 的档位数 N**，编号一一对应，不多不少
2. `### 暴力参照版` **必出**；若档位 1 的做法本身就是朴素暴力，则与之合并，只写 `### 版本 1｜档位 1：暴力`，并注明「本版即暴力参照」
3. **`### 版本 N｜档位 N：满分解`** 必为最优解，覆盖全部约束，符合 NOI 标准
4. 每版标题下先写两三句小引，说清四件事：
   - 本版对应哪一档（测试点范围 / 特殊性质）
   - 相比上一版改了什么
   - 时间复杂度
   - 大概能拿多少分

## 版本与档位对照

正文中附一张表，把 step 4 的阶梯落到代码版本上：

```
| step 4 档位 | 本步版本小节 | 该档约束 | 时间复杂度 | 可拿分 |
|-------------|--------------|----------|------------|--------|
| 1 | 版本 1｜档位 1：暴力 | $n \le 10$ | $O(n!)$ | 20 |
| 2 | 版本 2｜档位 2：链 | 树退化成链 | $O(n)$ | 50 |
| 3 | 版本 3｜档位 3：满分解 | $n \le 2 \times 10^5$ | $O(n)$ | 100 |
```

## 完整可提交（要务）

- 每版都是**完整程序**：含头文件、全局定义、`main()`，能直接编译提交
- **禁**伪代码、**禁**「此处省略」「其余同上」、**禁**只给关键片段
- 每版各写各的，不复用上版残缺代码
- 代码头注释中的「算法 / 时间复杂度 / 空间复杂度」按**本版**填写，勿照抄满分版

## 代码规范（NOI 标准）

| 项 | 要求 |
|----|------|
| 头文件 | `<bits/stdc++.h>` 万能头 |
| 标准 | C++11 |
| 同步 | `ios::sync_with_stdio(false); cin.tie(nullptr);` |
| 变量 | 简短字母优先（`n`, `m`, `ans`, `dp`），不超 4 字母为主 |
| 全局优先 | 大数组、常量、常用变量放全局，防爆栈 |
| STL | 合理使用，勿滥用；竞赛风格优先数组 |
| 函数 | 核心逻辑封 `solve()` 等，避免超长 `main` |
| 魔法数字 | 禁；常量须命名并注释意义 |

> 暴力参照版可放宽规范（如用 `next_permutation`、递归枚举），但须能运行、能过样例。

## 注释要求

1. **行首步骤注释**：`// Step1: 预处理前缀和`
2. **段落注释**：复杂逻辑块说明，如 `/* 线段树区间更新: O(log n) */`
3. **常量注释**：`const int MOD = 1e9 + 7; // 质数模数防溢出`
4. **易错点注释**：标边界场景（`n = 0`、极大值溢出、数组越界）
5. 注释一律**中文**，代码本身即为教学材料

## 铁律：写后即验

### 其一：过样例

每版都跑题面样例（含该档能覆盖的样例），输出须与题面一致：

```bash
cd {输出目录}
g++ v1.cpp -o v1 -std=c++17
printf '样例输入1\n' | ./v1     # 对照题面样例输出1
```

- 满分解必过**全部**样例；未过则改至全过
- 每版都过其能覆盖的样例，不止验一版

### 其二：边界手推

- 手推 2~3 组边界数据（最小值、最大值、退化情形），核对输出与推导是否一致
- 极端规模**不实跑**，按运算量估算是否超时限（推导见 step 6）

### 其三：禁

- 禁未过样例即写下一版
- 禁满分解样例未过仍续写 step 6
