# NOI金牌教练级题解生成器

本技能严格对标NOI信息学奥赛金牌教练标准，为每道算法竞赛题目自动生成深度解析文档，并固定输出至指定目录，命名统一为“题目编号_题目名称.md”。

## 一、触发条件

- 用户给出任意算法竞赛题目 URL（LeetCode/洛谷/AtCoder/Codeforces等）或题目描述内容。
- 用户要求“生成题解”、“按金牌教练标准输出题解”或“生成完整解析”。

## 二、执行流程（全自动）

1. **获取题目**：利用网页抓取工具（如 WebFetch 等）读取题目 URL，提取标题、题面、数据范围、样例等完整信息。
2. **生成解析**：严格按照下方的【三、内容与排版规范】生成 Markdown 题解内容。
3. **保存文件**：将生成的 Markdown 内容保存至 `/Users/hanshilin/Desktop/hanshilin/magao/NOI/base/hydroj/生成题解文件` 目录下，文件名为 `题目编号_题目名称.md`（如 `P1510_精卫填海.md`）。目录不存在时需自动调用工具创建。

## 三、内容与排版规范（强规则）

题解必须严格遵循以下结构生成，不得随意删减标题模块，确保知识点拆解的层级一致：

### 1. 文档结构与要求

- `# 题目编号 题目名称` （一级标题，如 `# P1510 精卫填海`）
- `## 题目描述`：精简提取题意背景和目标，包含形式化需求和隐式约束（如内存/时间限制）。
- `## 输入格式`：说明输入的变量和顺序。
- `## 输出格式`：说明输出的要求。
- `## 输入输出样例`：使用 `### 样例1` 等三级标题，并在 ` ```text ` 块中展示输入输出，包含对边界样例的解释。
- `## 数据范围`：列出数据规模及限制条件，明确标注极端边界（如 $n \le 10^5$）。
- `## 算法分析`：必须拆分为以下三级标题，展示从暴力到最优的思维演进：
  - `### 问题建模`：用数学或算法语言重新描述问题。
  - `### 算法演进`：按照时间复杂度逐步优化的方式进行改进，清晰展示算法演进路径。首先分析初始算法/暴力解法的时间复杂度并识别性能瓶颈（如 $O(n^3)$ 为何超时）；然后针对每个优化步骤，说明优化原理和技术细节，并明确标注时间复杂度的变化（如从 $O(n^2)$ 优化到 $O(n \log n)$）；最后推导得出最优解的思路。
  - `### 状态定义与转移`（DP/图论等适用）：明确状态转移方程或核心推导过程。
  - `### 算法步骤`：最优解法的执行流程序号列表。
- `## 代码实现`：提供逐步优化的完整可运行代码，必须包含详尽注释：
  - `### 初始/暴力版本`（必选）：提供初始算法的完整代码实现，包含详细注释说明算法逻辑。
  - `### 优化版本 X`（必选）：根据算法演进路径，提供每个中间优化步骤的改进后代码版本，并详细注释说明优化原理和复杂度变化。
  - `### 最优版本`（必选，必须符合 NOI 标准）：提供最优解的完整代码实现，包含算法思路、时间复杂度分析和详细注释。对比展示每个优化版本的性能差异，提供测试用例验证优化效果。确保所有代码都遵循最佳实践，包含完整的错误处理和边界条件处理。
- `## 复杂度分析`：细化推导过程：
  - `### 时间复杂度`：主算法的时间复杂度及严谨推导证明。
  - `### 空间复杂度`：包含输入存储与辅助空间的分析。
- `## 边界情况与易错点`：列举特殊数据的处理方式（空输入、极限值、退化图），指出学生易错点（如初始化、数组越界）和调试技巧。
- `## 总结`（可选）：对题目考察点进行核心归纳。

### 2. 代码规范 (NOI 标准)

- **环境标准**：统一使用 `<bits/stdc++.h>` 万能头文件，代码开头关闭 STL 同步。使用 C++11 标准。
- **代码风格**：符合 NOI 竞赛风格，**多使用全局数组/变量**，少使用局部变量；合理使用数组，减少不必要的 STL 滥用。
- **变量命名**：变量名称尽量简短，多用字母（一般不超过4个字母，如 `cnt`, `ans`），或使用物理含义清晰的驼峰命名（如 `nodeCnt`, `maxDepth`）。
- **注释要求**：行首需有步骤注释（如 `// Step1: 预处理前缀和`），复杂逻辑要有段落注释（如 `/* 线段树区间更新: O(logn) */`），常量需说明意义（如 `const int MOD = 1e9+7; // 质数模数防溢出`）。

### 3. LaTeX 与 Markdown 强制规范

- **数组下标**：必须使用 `a_i`，禁止使用 `a[i]` 或 `a\_i`。
- **区间表示**：必须使用 `[L, R]`，禁止使用 `\[L, R]`。
- **数学环境**：所有的变量、数字、公式**必须**使用 LaTeX，行内使用 `$expr$`，行间独立公式使用 `$$expr$$`。
- **代码块**：统一使用 `cpp` 高亮（即 ` ```cpp `），并保持排版简洁明了。
- **内容深度**：每份题解应具备竞赛级深度（通常不少于200行内容），确保高质量输出。
