# GESP 理论卷题包格式

**模版实例**：`template/`（题面为 **GESP202506 一级客观题**：15 道单选 + 10 道判断，全局题号 1–25）。

## 三件套

| 文件 | 作用 |
|------|------|
| `problem.yaml` | 题号、标题、标签、难度、时空限制、统计字段 |
| `problem_zh.md` | 试卷正文（分节、题干、`select`、选项） |
| `testdata/config.yaml` | 客观题答案与分值 |

## 1. problem.yaml

- **pid**：平台题号（新卷须换新 pid，勿与模版 `GESP5000` 冲突）。
- **title**：与 `problem_zh.md` 首行 `#` 标题一致。
- **tag**：如 `GESP一级理论`（级别 +「理论」）。
- **difficulty** / **time** / **memory**：与模版同级卷一致即可（模版为 `3` / `1s` / `512m`）。
- **nSubmit** / **nAccept**：可置 `0`，导入后由系统统计。

## 2. problem_zh.md

1. 首行一级标题：`# 试卷标题`。
2. 大节用二级标题，可带分值说明，例如：  
   `## 一、单选题（每题 2 分，共 30 分）`、`## 二、判断题（每题 2 分，共 20 分）`。
3. 每题一行起笔：**`第n题`** + 题干（可含 `` `代码` ``、 fenced `cpp` 代码块）；判断题题干常以 `（）` 结尾。
4. 题干与选项之间插入 **`{{ select(全局序号) }}`**，全卷从 **1** 连续编号到最后一题（模版为 1–25）；**各节内「第 n 题」从 1 重新计，但 `select` 不重新计**。
5. 选项每行以 **`+ `** 开头；选项文字建议用反引号包裹，如 ``+  `输入设备` ``。  
   - 单选题：通常 4 项。  
   - 判断题：固定两项 ``+  `true` ``、``+  `false` ``（题面写法；见下节 config）。

生成新卷时对照 `template/problem_zh.md` 改内容与题量，**不改上述骨架**。

## 3. testdata/config.yaml

```yaml
type: objective
answers:
  '1':
    - C    # 单选：A–D
    - 2    # 该题分值
  '16':
    - A    # 判断：A 表示 true，B 表示 false（与青石客观题惯例一致）
    - 2
```

- **题号**（键）与题面中 `{{ select(N) }}` 的 **N** 一一对应。
- 每题答案列表为 **`[答案, 分值]`** 二元组。
- 判断题在 config 里用 **A/B**，不用字面量 `true`/`false`。

## 自检

- [ ] `select` 序号连续、与 `answers` 键集合一致  
- [ ] 单选答案在 A–D；判断答案在 A/B  
- [ ] `title`、Markdown 标题、`tag` 级别一致
