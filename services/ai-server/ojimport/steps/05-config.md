## 配置格式

```yaml
pid: abc453a
title: "移除前导o(Trimo)"
tag:
  - "字符串"
  - "模拟"
  - "GESP一级"
```

## 注

1. pid 按规而判，非无脑填 null
2. **title 只写题目名称**：`中文标题(英文原标题)`。**禁**带 `GESP X级｜` 之类前缀——级别一律由 tag 承载，不写进标题。
3. **tag 优先复用站内已有标签**（清单见下）。算法/知识点已在清单内 → 原样照搬，**禁**自造近义词（已有「最短路」就不要写「最短路算法」，已有「并查集」就不要写「DSU」）。
4. **清单里没有的算法才新增标签**：中文、无空格、无标点，长度与粒度向站内既有标签看齐（如站内有「线段树」，新算法就写「可持久化线段树」）。
5. **多级完整**：大类与子类都要打，不省上层。例：
   - `图论` + `最短路`
   - `动态规划` + `背包`
   - `数据结构` + `并查集`
   - `数据结构` + `树状数组`
   - `倍增` + `ST表` + `RMQ`
6. **等级标签必带且仅带一个**：`GESP一级`~`GESP八级`（中文数字、无空格，与站内既有标签一致；**禁**写 `GESP 1级`）。来源为官方真题时另加 `官方真题`；理论卷用 `GESP一级理论`~`GESP八级理论`。
7. 数量：知识点标签 2~4 个，加等级标签合计 3~5 个。

## 测试数据分组配置（`testdata/config.yaml`）

分组写在 `{WORK_DIR}/testdata/config.yaml`（HydroOJ subtask 格式，样例见 **`question/testdata/config.full.yaml`**）。铁律：

1. **题面给了测试点说明 → 严格照抄**：题面写明测试点总数、各点规模上限、特殊性质、分值或百分比时，`subtasks` 的分值、测试点区间、分组个数一律与题面一一对应，**禁**套默认 5 组敷衍。
2. **题面没给 → 才走默认分组**：25 组数据 + 默认 5 组（样例 10 / 小规模+特殊 20 / Hack 15 / 中大规模 30 / 随机回归 25）。
3. 分值合计恒为 100；测试点区间不重叠、不漏点（服务端会校验）。

对应 JSON 字段（见 `prompts/single_preamble.md` 与 `steps/07-testdata.md`）：

| 题面情况 | `total_cases` | `subtasks` |
|---|---|---|
| 写明「共 N 个测试点」+ 分值/性质表 | `N` | 逐点照抄，如 `[{"score":30,"cases":"1-3"},{"score":70,"cases":"4-10"}]` |
| 只给百分比（如 20%/40%/40%） | 省略（25） | 按百分比设分值，如 `[{"score":20,"cases":"1-5"},{"score":40,"cases":"6-15"},{"score":40,"cases":"16-25"}]` |
| 都没给 | 省略（25） | 省略（用默认分组） |

`cases` 写法：`"1-4"`、`"1,3,5"`、`"1-4,7"` 均可。题面说「测试点 1~4」就写 `"1-4"`，编号须与测试点编号一致。
