# Step 12: 入库后归类训练

## 目标

题包已成功入库（题号落库、`docId` 已生成）之后，按题目标签把它归入青石训练课程（`docType: 40`，域 `system`）；缺课程或章节时按规则新建。

## 何时执行

- 在 `08-package.md` 打包 → 上传导入**成功之后**，作为收尾步骤。
- 只对已落库的题执行；题号不在库里的直接跳过。
- 可反复执行：已在章节内的题不会重复追加。

## 站内规则（取自库内现有 29 门课程，勿臆造）

| 项 | 规则 |
|------|------|
| 课程 | `document` 表 `docType: 40`；正文（`content`）、简介（`description`）、`dag` |
| 章节 | `dag` 数组元素 `{_id, title, requireNids, pids}`；`pids` 存题目 **`docId`（数字）**，不是平台题号 |
| 去重 | 一门课内一道题只出现在一个章节；同一题可以同时属于「算法课」和「GESP{n}级真题训练」 |
| 标注 | `dtoj: {direction, kind, notes}`；direction 取值 `GESP`/`CSP-X`/`CSP-J`/`CSP-S`/`NOIP`/`其他`，kind 取值 `GESP理论训练`/`GESP真题训练`/`基础入门`/`算法专题`/`集训` |
| 排序 | 训练列表顺序存 `domain.dtojTraining.order`，新课程追加到末尾 |
| 讲义 | `dtoj.notes[章节_id]`；不写则前端回退为「讲义待补充」 |

## 路由

按标签判断，自上而下取第一条命中：

| 标签情况 | 课程 | 章节 | kind / direction |
|------|------|------|------|
| `GESP{n}级理论` | `GESP{n}级理论训练` | 认证场次，如 `2026年3月认证`；标题带「模拟」→ `模拟卷` | `GESP理论训练` / `GESP` |
| `GESP{n}级` | `GESP{n}级真题训练` | 算法**大类**（缺则新建） | `GESP真题训练` / `GESP` |
| 其余 | 算法**大类**标签 | 主算法标签（须落在既有教材章节，见下） | `算法专题` / `CSP-J`（方向表内的算法为 `CSP-S`） |

> 等级标签即定课：只要带 `GESP{n}级` 就归 `GESP{n}级真题训练`，**不要求**另带 `官方真题`。站内 198 道带等级标签的题里 197 道另带 `官方真题`，但模型偶有漏标（如 P8815 漏标），漏标不该把题改道去算法课。

### 章节命名分两套体系

站内现状（`docType 40` 全量比对得出，勿臆造）：

- `GESP{n}级真题训练` 章节是扁平知识点：`数学`、`排序`、`树`、`动态规划`……缺则新建，与既有命名同体系。
- `GESP{n}级理论训练` 章节是认证场次：`2025年12月认证`、`模拟卷`。
- `算法专题` / `基础入门` 章节是**教材小节名**：`基础(二) 第九章 动态规划背包问题`、`基础(三) 第四章 最短路径`、`基础(四) 数据结构 树状数组`。这类课**只往既有章节里放，不新建章节**。

教材类的章节解析（`resolve_chapter`）：按标签顺序取子类标签、再取大类，逐个在既有章节标题里做**字面包含**匹配。

| 标签 | 命中章节 |
|------|------|
| `背包` | `基础(二) 第九章 动态规划背包问题` |
| `最短路` | `基础(三) 第四章 最短路径` |
| `拓扑排序` | `基础(三) 第四章 拓扑排序与关键路径` |
| `并查集` / `LCA` / `线段树` / `树状数组` | 同名章节 |

匹配不到、或匹配到多章（有歧义）→ **不归类**，日志写明候选与原因，等人工放入。宁可不收，不造与教材编排不一致的裸话题章节。同理，教材类课程不存在也不自动新建。

- **主算法**：标签里第一个非等级、非 `官方真题`、非 `其他` 的标签。等级标签是 `GESP一级`~`GESP八级`。
- **大类 / 子类**（表外的标签本身即大类）：

  | 大类 | 子类标签 |
  |------|------|
  | 动态规划 | 背包、区间DP、树形DP、状压DP |
  | 图论 | 最短路、最小生成树、拓扑排序、LCA、连通性 |
  | 数据结构 | 并查集、树状数组、线段树、平衡树 |
  | 倍增 | ST表、RMQ |
  | 分治 | 二分 |
  | 前缀和 | 差分 |
  | 数论 | 质数、约数、筛法、快速幂、逆元 |

- 一题只归**一门**算法课程（与站内现状一致：没有题同时落在两门非 GESP 课程）。
- 新建算法课程的方向：`图论`、`数据结构`、`线段树`、`树状数组`、`倍增`、`网络流`、`分块`、`莫队`、`树链剖分`、`主席树`、`平衡树` 记 `CSP-S`，其余记 `CSP-J`。已有课程沿用其原 `dtoj.direction`，不改。

## 新建规则

只适用于 `GESP{n}级真题训练` / `GESP{n}级理论训练`（章节扁平、缺则补）：

- **课程不存在** → 新建：`title` = 课程名；`content` = `题库自动归档 · {课程}`；`description` = `{课程} 训练（按题目标签自动建立）`；`dtoj = {direction, kind, notes: {}}`；`owner = 3`；`attend = pin = 0`；并追加进 `dtojTraining.order`。
- **章节不存在** → 追加到 `dag`：`_id` = 现有最大 `_id` + 1，`title` = 章节名，`requireNids = []`，`pids = [该题 docId]`。
- 不写章节讲义，前端按「讲义待补充」回退。

`算法专题` / `基础入门` 不走这两条：课程或章节不存在就不归类，交给人工。

## 执行

ai-server 自动导入成功后**已顺带执行**（日志里出现 `step12: 归类训练课程` 与归类结果行）。下面的命令用于本机补跑、回填历史题，以及改标签后重归。

实现只有一份：`services/ai-server/app/training.py`；本机脚本是它的入口。

```bash
cd <Hydro-magao 仓库根>
python3 scripts/classify_training.py --pid aip3f2a1b              # 平台题号
python3 scripts/classify_training.py --doc-id 794                 # 题面无平台题号时用 docId
python3 scripts/classify_training.py --import-log <题包目录>/_import.log
python3 scripts/classify_training.py --pid aip3f2a1b --dry-run    # 先看归类结果再落库
```

输出形如：

```
doc:794 → 动态规划 / 背包｜新建章节
doc:807 → 字符串 / 字符串｜新建课程+章节
pid:GESP12512 → GESP一级理论训练 / 2025年12月认证｜已在章节内
```

动作有四种：`新建课程+章节`、`新建章节`、`追加`、`已在章节内`。

## 注意

- 只对**本次新入库**的题号执行。不要拿历史整批 `_import.log` 重跑：已在某门课里的题会被再收进另一门课，形成重复。
- 语法类标签（`分支`、`循环`、`数组`…）会各自建出一门算法专题课。这是既定规则；若不想让语法标签开课，先在 `05-config.md` 的标签清单里把它们并入 `基础语法` 之类的课名。
