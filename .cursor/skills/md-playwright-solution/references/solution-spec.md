> 本文件为 `md-playwright-solution` 的格式与规范总纲。steps 各步骤遇格式细节，一律引此处。

## 二、内容深度要求

| 项 | 要求 |
|----|------|
| 正文长度 | 不少于 200 行 |
| 算法演进 | **分档阶梯**：至少 2 档，含特殊性质档或最小范围档；每档标注复杂度与可拿分 |
| 分档对齐 | 「问题建模」的数据范围表、「算法演进」的档位、「代码实现」的版本三者一一对应 |
| 代码 | 按档位齐全：每档一版（`### 版本 k｜档位 k`）+ 暴力参照版；每版须完整可提交、该档可 AC |
| 复杂度 | 先出「各档复杂度汇总表」（档位 / 复杂度 / 该档最大 $n$ / 可拿分），再详推满分解 + 与数据范围的自洽性验证 |
| 易错点 | 先列各档特有陷阱，再列通用易错点；贴合本题，禁泛泛罗列 |

### 算法演进写法（分档阶梯）

**不做「暴力→正解」的一步跳，而是沿数据范围排阶梯，逐档拿分。**

0. 先读 `## 数据范围` 与「说明/提示」，抄出各档规模、特殊性质与分值
   - 题目给了 Subtask / 特殊性质 → 严格按其分档
   - 没给 → 按量级自划 3~4 档（如 $n \le 20$ / $n \le 5000$ / $n \le 2 \times 10^5$ / 极限）
1. **阶梯总览表**：档位 | 做法 | 时间复杂度 | 可拿分
2. 每档用小节（`#### 档位 N：...`）写清，固定答四问：
   - 本档约束是什么
   - 上一档做法为何不够（给具体运算量）
   - 本档新做法是什么（原理 + 技术细节）
   - 复杂度是多少、为何这档能过（标注复杂度变化，如 $O(n^3) \to O(n^2)$）
3. **优先攻特殊性质档 / 最小范围档**：这类档有极简做法，是保底分，且常揭示正解的关键观察
4. 再逐档撤掉特殊性质、放大量级，每档只消一个瓶颈
5. 末档收进满分解，覆盖全部约束
6. 每档做法与 `## 代码实现` 的版本一一对齐（档位 k → `### 版本 k｜档位 k`，末档 → 满分解；另出暴力参照版）
7. 禁用「显然」「容易想到」等跳过推导的表述

## 三、NOI 代码规范

| 项 | 要求 |
|----|------|
| 头文件 | `<bits/stdc++.h>` 万能头 |
| 标准 | C++11 |
| 同步 | `ios::sync_with_stdio(false); cin.tie(nullptr);` |
| 变量命名 | 简短为主（≤4 字母），如 `cnt`、`ans`；语义清晰的驼峰亦可（`nodeCnt`、`maxDepth`） |
| 全局优先 | 大数组、常量放全局，防爆栈；少用局部 |
| 数组优先 | 竞赛风格多用数组，合理使用 STL，勿滥用 |
| 函数划分 | 核心逻辑封 `solve()` 等，避免超长 `main` |
| 魔法数字 | 禁；常量须命名并注释意义，如 `const int MOD = 1e9 + 7; // 质数模数防溢出` |

### 注释要求

1. **行首步骤注释**：`// Step1: 预处理前缀和`
2. **段落注释**：`/* 线段树区间更新: O(log n) */`
3. **常量注释**：标意义
4. **易错点注释**：标边界场景（`n = 0`、溢出、越界）
5. 注释一律**中文**，代码本身即教学材料

### 代码文件头模板

```cpp
/**
 * 算法：[本版核心算法名称]
 * 时间复杂度：O()
 * 空间复杂度：O()
 *
 * 核心思路：
 * 1. [一句话核心逻辑]
 * 2. [关键状态转移或操作]
 */
```

> 各版按**本版**的算法与复杂度填写，勿照抄满分解。暴力参照版可放宽规范（如用 `next_permutation`、递归枚举），但须可运行、能过样例。

## 四、LaTeX 与 Markdown 强制规范

| 项 | 正 | 误 |
|----|----|----|
| 数组下标 | `$a_i$` | `a[i]`、`a\_i` |
| 区间表示 | `$[L, R]$` | `\[L, R]` |
| 行内公式 | `$n \le 10^5$` | 裸写 `n<=10^5` |
| 行间公式 | `$$dp_i = \max(dp_{i-1}, dp_{i-2} + a_i)$$` | 混入正文 |
| 代码块 | ` ```cpp ` | ` ```c++ `、无语言标签 |

- 所有变量、数字、公式**必**用 LaTeX
- 代码块统一 `cpp` 高亮，排版简洁

## 五、样例与图文

1. 样例逐组编号（`### 样例1`），输入/输出**逐字复制**
2. 样例解释仅译原题，无则省，禁编造
3. 题面原有图片链接（`![](url)`、`<img>`）原样保留
4. 原题公式、表格、示意图完整保留

- 编号原样保留大小写：`P1510`、`CF1891B`、`abc453a`
