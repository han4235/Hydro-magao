# Step 3: 写题面部分

## 目标

自底稿写题解的题面段：`## 题目描述` ~ `## 数据范围`。

底稿取法（见 step 2）：

| 原题语言 | 底稿 |
|----------|------|
| 中文 | `{题目编号}_raw.md` |
| 非中文 | `{题目编号}_zh.md`（译文）；核对样例/边界时回查 `_raw.md` 原文 |

## 结构（强规则）

```
# 题目编号 题目名称

## 题目描述
（精简题意背景与目标；含形式化需求与隐式约束，如时空限制）

## 输入格式
（输入的变量与顺序）

## 输出格式
（输出的要求）

## 输入输出样例

### 样例1
输入：
（样例输入原文）

输出：
（样例输出原文）

（必要时补对该样例的解释）

### 样例2
（多组样例同构）

## 数据范围
（规模与限制，标极端边界，如 $n \le 10^5$）
```

一级标题固定为 `# 题目编号 题目名称`（如 `# P1510 精卫填海`）。

## 铁律：仅译不编

1. 题面**仅译不编**：禁分析、推理、计算过程
2. **样例逐字复**：不增删改任一字
3. **样例解释**：原题有则必译，无则省该段
4. **提示/说明**：原题有则必译；数据规模若写在此处，一并保留
5. **图片/公式/表格**：原样留，勿删勿替
6. **非中文原题**：译文须承接 step 2 的译稿，术语与前文一致；不确定处回查 `_raw.md`，禁按印象重译

## 数据范围细则

| 情形 | 写法 |
|------|------|
| 原题独立列「数据范围」 | 用 `## 数据范围` |
| 原题并入「说明/提示」 | 保留在提示内，不再重复单列 |
| 两者皆无 | 自题面推断，标「（据题意推断）」，禁编造精确值 |

### 分档信息必完整保留（要务）

step 4 要**照题面排分档阶梯**，故此题面段必须把分档信息**原样搬全**，禁概括、禁漏：

| 必保留项 | 例 |
|----------|----|
| 各档规模 | 测试点 1~4：$n \le 10$；5~10：$n \le 500$ |
| 特殊性质 | 树退化成链、图是 DAG、序列单调不减、$k = 1$ |
| 各档分值 | 前四档 20 分、特殊性质档 30 分、满分 50 分 |
| 时空限制 | 1 s / 256 MB |

- 题面用文字写（如「对于 100% 的数据…」「特殊性质 A：…」）→ **逐句保留**，勿改写成表格
- 题面用表格列 Subtask → **原表照抄**
- 极端边界单独标出（如 $n = 1$、$n \le 10^5$、$\lvert x_i \rvert \le 10^9$）

标注完此节，step 4~6 的复杂度与档位才有据可依。

## 写入前自检

1. 标题的编号、名称与 step 1 一致
2. 各组样例输入/输出与原文逐字一致
3. 原题有的样例解释、提示均已译入
4. 图片、公式、表格未遗漏
5. **分档信息（各档规模 / 特殊性质 / 分值）已完整保留**，供 step 4 排阶梯
6. **非中文原题通读一遍**：译文无逻辑错、限定词（至多/至少/恰好）与原文等价、术语全篇统一、样例按译文规则能推出样例输出
