# Step 4: 写算法分析

## 目标

写 `## 算法分析` 段。重点**不是**从暴力一步跳到正解，而是**贴着数据范围的分档阶梯，一档一档往上拿分**：先攻特殊性质档 / 小范围档，再逐层加深，直到满分解。每档都要有完整的递进思路与复杂度分析。

## 前置：先读数据范围（要务）

动手写前，自 step 3 的 `## 数据范围` 与「说明/提示」抄出分档信息：

| 要素 | 例 |
|------|----|
| 各档规模 | 测试点 1~4：$n \le 10$；5~10：$n \le 500$ |
| 特殊性质 | 树退化成链、图是 DAG、序列单调不减、$k = 1$ |
| 各档分值 | 前四档 20 分、特殊性质档 30 分、满分 50 分 |
| 时空限制 | 1 s / 256 MB |

- 题目**给了**特殊性质或分开的 Subtask → **严格按它的分档**排阶梯
- 题目**没给** → 按数据量级自划 3~4 档，如 $n \le 20$ / $n \le 5000$ / $n \le 2 \times 10^5$ / 极限

## 结构（强规则）

标题顺序固定，**不得改名、不得调序**：

```
## 算法分析

### 问题建模
### 算法演进
### 状态定义与转移
### 算法步骤
```

其中 `### 状态定义与转移` 为**条件必出**：适用于 DP / 图论 / 数据结构题。非此类题型可省该 H3，但**必须在 `### 算法演进` 内显式注明**「本题不涉及状态转移定义，原因：……」。其余三个 H3 无条件必出。

## 各节细则

### 问题建模

1. 形式化：输入 $X$、输出 $Y$、目标 $\max / \min f$、约束
2. 点明题型归属（区间 DP、最短路、二分答案、树形 DP 等）与 NOI 大纲知识点
3. **必附「数据范围与分档」表**（承前一步的抄录）：

```
| 档位 | 测试点 | 规模 / 特殊性质 | 分值 |
|------|--------|-----------------|------|
| 1 | 1~4 | $n \le 10$ | 20 |
| 2 | 5~10 | 树为链 | 30 |
| 3 | 11~20 | 无特殊性质，$n \le 2 \times 10^5$ | 50 |
```

后续「算法演进」逐档对应此表，档位编号保持一致。

### 算法演进（核心）

**沿分档阶梯从易到难推进，一档一小节，用四级标题分开：**

```
#### 阶梯总览
#### 档位 1：特殊性质 / 最小范围
#### 档位 2：……
#### 档位 N：满分档
```

**阶梯总览**：一张表列出每档的做法与复杂度，读者一眼看清演进路径。

```
| 档位 | 做法 | 时间复杂度 | 可拿分 |
|------|------|------------|--------|
| 1 | 全排列枚举 | $O(n!)$ | 20 |
| 2 | 区间 DP | $O(n^3)$ | 50 |
| 3 | 前缀和优化 DP | $O(n^2)$ | 100 |
```

**每档小节固定答四问**（缺一不可）：

1. **本档约束是什么**：把该档的规模/特殊性质单独拎出来说
2. **上一档做法为何不够**：算运算量，给具体数字。例：$O(n^3)$、$n = 500$，约 $1.25 \times 10^8$ 次，勉强；$n = 5000$ 则 $1.25 \times 10^{11}$，必 TLE
3. **本档新做法是什么**：讲原理与技术细节。用到了哪条特殊性质、消除了哪层枚举、换了什么数据结构
4. **复杂度与可行性**：标注复杂度变化（如 $O(n^3) \to O(n^2)$），并说明为何这档能过

**推进方向：**

- 若有特殊性质档 → **先写它**。这类档往往有极简做法（如链上即一维 DP、$k=1$ 退化为最短路），是全场最稳的保底分，也常揭示正解的关键观察
- 再逐档撤掉特殊性质、放大量级，每档只解决一个瓶颈
- 最后一档收进正解，覆盖全部约束

**遣词禁令**：禁「显然」「容易想到」「稍加分析可知」等跳过推导的表述。每步都要有可核对的复杂度数字。

**与 step 5 的对应**：每档做法对应 `## 代码实现` 里的一版代码，**档位编号与版本编号一一对齐**（档位 k → `### 版本 k｜档位 k：…`，末档 → `### 版本 N｜档位 N：满分解`）。另有 `### 暴力参照版`（若档位 1 本身即朴素暴力，则与之合并）。

### 状态定义与转移

DP / 图论 / 数据结构适用。非此类题型可省本 H3，但须在「算法演进」中注明不适用原因。

- DP：状态含义、边界、转移方程（行间公式）
- 图论：点边含义、算法选择理由
- 数据结构：维护的信息与不变量

若各档状态定义不同（低档用暴力状态、高档用压缩状态），按档分别写清。
