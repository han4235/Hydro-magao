## 时间复杂度

### 先出「各档复杂度汇总表」（要务）

把 step 4 的阶梯落到复杂度上，读者一眼看清每档的成本与收益：

```
| 档位 | 做法 | 时间复杂度 | 空间复杂度 | 该档最大 $n$ | 可拿分 |
|------|------|------------|------------|--------------|--------|
| 1 | 全排列枚举 | $O(n!)$ | $O(n)$ | 10 | 20 |
| 2 | 区间 DP | $O(n^3)$ | $O(n^2)$ | 500 | 50 |
| 3 | 前缀和优化 | $O(n^2)$ | $O(n^2)$ | 5000 | 80 |
| 4 | 斜率优化 | $O(n)$ | $O(n)$ | $2 \times 10^5$ | 100 |
```

### 再详推满分解

- 给**紧确界**：$O(n \log n)$、$O(n^2)$
- 给**推导**：逐层循环次数 → 求和 → 结果
  - 例：外层 $n$ 次，内层均摊 $\log n$ 次，故 $O(n \log n)$
- 结合数据范围**验证可行性**：
  - $n \le 10^5$、时限 1s → 约 $10^8$ 次运算上限，$O(n \log n)$ 可过，$O(n^2)$ 不可
- 多阶段 / 均摊分析要分别说明
- 中间档的复杂度顺带验证「为何正好卡在该档边界」（体现分档动机）

## 空间复杂度

- 输入存储、辅助数组、递归栈分别计
- 大数组估算：`int a[200005]` 约 0.8 MB
- 标出是否接近内存限制（如 256 MB）
- 若各档空间开销差异大（如低档 $O(n^2)$ 会 MLE），一并说明

## 边界情况与易错点

先写**各档特有陷阱**，再列通用易错点：

| 档位 | 该档特有陷阱 |
|------|--------------|
| 低档（暴力） | 递归枚举爆栈、多测未清空、`next_permutation` 用错比较器 |
| 中间档 | 复杂度刚好卡界，常被构造数据卡常数 → 需卡常或换做法 |
| 满分档 | 优化后的状态初值、下标偏移、压缩后边界越界 |

通用易错点：

| 类别 | 要点 |
|------|------|
| 极限值 | $n = 0$ / $n = 1$、全相同元素、退化图（链 / 菊花） |
| 溢出 | `int` 相乘爆范围 → 用 `long long`；取模前先降 |
| 初始化 | DP 初值、`ans` 置 $-INF$ 而非 0、数组清零 |
| 越界 | 数组开够（多开 5~10）、下标从 0 还是 1 要统一 |
| 精度 | 浮点比较用 `eps`、整数除法向下取整 |
| 读入 | 多组数据清空、`getline` 吞换行 |
| 调试 | 打印中间变量、极端数据手造 |

每类挑**本题真正相关**的写，禁罗列无关条目。
