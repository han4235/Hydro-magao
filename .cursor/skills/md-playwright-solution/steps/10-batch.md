# Step 10: 多题 / 题单

## 目标

对一组题目（题单、比赛、批量 URL）逐题产出题解。

## 流程

1. 读 `00-detect-input.md` 确为多题
2. **列清单**：把全部题号/URL 写成一个清单文件（对话内列表或 `_todo.md`），逐条勾
3. 对每题依序跑 `01-init.md` → `02` → `03` → `04` → `05` → `06` → `07` → `08` → `09`
4. 每题独立落盘，不复用上题任何结论、代码、复杂度
5. 收尾出汇总报告

## 铁律

- **一处一题**：每题独立抓题面、独立建模，禁跨题套模板
- **样例逐字**：各题样例各自核对，禁想当然
- **顺序可控**：用户给定顺序 → 从其顺序；未给 → 按清单原序
- **可中断续跑**：每完成一题即落盘，中断后从清单未勾项接着来
