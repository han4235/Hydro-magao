# Step 1: 初始化输出

## 目标

定输出目录、题目编号、题目名称与文件名。

## 输出目录

**默认：**

```
/Users/hanshilin/Desktop/hanshilin/magao/NOI/base/hydroj/生成题解文件
```

- 用户另指定目录 → 从其指定
- 目录不存在 → 先建
- 全部题解**平铺**该目录，不按题单/日期再分子目录（用户未要求时）

## 题目编号

依 URL / 题号 / 页面标题提取，原样保留大小写：

| 来源 | 例 |
|------|----|
| 洛谷 | `P1510` |
| Codeforces | `CF1891B` |
| AtCoder | `abc453a` |
| CSES | `CSES1130` |

皆取不到 → 记 `null`，问用户。

## 题目名称

- 中文题名优先（如 `精卫填海`）
- 英文题名保原样，空格转下划线（如 `Deja_Vu`）
- 名称所含 `/`、`\`、`:`、`*` 等非法字符 → 全替换为下划线

## 文件名

**格式：** `题目编号_题目名称.md`

例：

- `P1510_精卫填海.md`
- `CF1891B_Deja_Vu.md`
- `abc453a_Trimo.md`

编号与名称之间用**半角下划线**。

## 工作文件名

抓题面后另落一份原文 `{题目编号}_raw.md`（step 2），题解正文另存为 `{题目编号}_{题目名称}.md`（step 9）。
