# Step 2: 抓题面

## 目标

取全题目信息：编号、名称、题述、输入/输出格式、样例、样例解释、提示、数据范围、时空限制。

## 工具优先级

```
1. Playwright / 浏览器工具（可执行 JS，能取内嵌 JSON）
2. WebFetch（公开页面，兜底）
```

## 抓取顺序（要务）

**结构化数据优先，勿只抓可见碎片文本即开写。**

1. Playwright 打开 URL，等页面稳定，核标题与 URL 是否对得上
2. 优先抽页面**内嵌结构化数据**：
   - 洛谷：`window._feInjection`（含 `content`、`samples`、`limits`、`tags`、`difficulty`）
   - Codeforces / AtCoder：页面 state、内嵌 JSON、公开接口
   - Hydro：题面 DOM 与附件
3. 无结构化数据 → 正文 DOM 分段提取
4. 仍不成 → WebFetch

## 必取字段

| 字段 | 说明 |
|------|------|
| 题目编号 | `P1510` 等 |
| 题目名称 | 中文名优先，附英文原名 |
| 题目描述 | 全文，勿删 |
| 输入格式 / 输出格式 | 原文 |
| 样例 | 输入/输出成对，逐字 |
| 样例解释 | 原题有则必取 |
| 提示 / 说明 | 含数据规模、部分分、特殊约定 |
| 数据范围 | 独立列出时 |
| 时空限制 | 时间 / 内存 |

## 保留铁律

1. **勿改样例**：输入/输出原封不动，禁增删改任一字
2. **留图片链**：`![](url)`、`<img>` 标签原样留
3. **留公式表格**：题面原有公式、表格、示意图完整留
4. **勿编造**：原题无样例解释则省，禁 AI 补写

## 非中文题面：先译后写（要务）

Codeforces / AtCoder / CSES 等多为英文题面，**必先译成中文**再进入 step 3。

### 分工

| 文件 | 语言 | 用途 |
|------|------|------|
| `{题目编号}_raw.md` | **原语言**，逐字 | 唯一事实源；样例、边界、数值以此为准 |
| `{题目编号}_zh.md` | 中文译稿 | step 3 的写作底稿 |

- 原题**本就是中文** → 不另生 `_zh.md`，直接以 `_raw.md` 为底稿
- 原题非中文 → **两份都留**：译稿便于写作，原文用于校对，防翻译引入误差

### 翻译要求

1. **贴合场景**：按题目实际背景选词。是「树」「图」「字符串」「背包」就照术语译，勿把游戏背景译成算法术语或反之
2. **术语统一**：同一概念全篇同一译法（如 `matching` 一律「匹配」，勿忽而「配对」忽而「匹配」）；术语按 NOI 惯例（`subtree` → 子树、`constraints` → 数据范围/说明）
3. **变量名与公式不译**：$n$、$m$、$a_i$、$\sum$、复杂度记号等原样保留，只译其外围的语文描述
4. **样例不译**：样例输入/输出里的数字、字符串、标点**原样照抄**；样例解释若含文字则译，数字与标识符照抄
5. **勿改语义（重灾区）**：
   - 不等号方向（$\le$ / $\ge$ / $<$）不得译反
   - 下标起止、模数、精度、单位、时间限制不得译错
   - 「at most / at least」「exactly / no more than」「distinct / different」等限定词须逐字对应，禁模糊化
   - 逻辑连接（and / or / but / such that）须译准，禁随手改成「并且/或者」造成条件放宽或收紧
6. **勿增勿删**：不补解释、不删条件、不合并句子导致丢失限定

### 译后必读（通读检查）

译完**从头通读一遍**，逐项核：

| 检查项 | 问题示例 |
|--------|----------|
| 上下文连贯 | 前文称「节点」后文忽称「点」，指代不清 |
| 前后呼应 | 输入格式说 $n$ 个数，输出格式却提 $m$，数量对不上 |
| 样例自洽 | 按译文的规则推样例，结果能对上样例输出 |
| 边界不矛盾 | 数据范围与描述冲突（如描述说可为负，范围写 $a_i \ge 1$） |
| 无逻辑错 | 条件被译宽/译窄，导致题意与原文不等价 |
| 可读懂 | 一个没看过原题的学生，只读译文能否明白题意 |

任一项不过 → 回原文对照重译该处，禁带着疑问进 step 3。

## 落底稿文件（要务）

抓完**即写**底稿，含全部信息（题述、格式、样例、解释、提示、范围、限制）：

- 中文原题 → 写 `{输出目录}/{题目编号}_raw.md`
- 非中文原题 → 写 `{输出目录}/{题目编号}_raw.md`（原文）+ `{输出目录}/{题目编号}_zh.md`（译稿）

> 后诸步骤（03~06）一律自底稿文件读取，**禁凭对话上下文记忆题面**。
