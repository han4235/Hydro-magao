# Step 9: 落盘与交付

## 目标

把题解写入固定目录，按规范命名，回报路径。

## 落盘路径

```
{输出目录}/{题目编号}_{题目名称}.md
```

- `{输出目录}` 见 step 1（默认 `NOI/base/hydroj/生成题解文件`）
- 目录不存在 → 先建
- 编码 **UTF-8**，换行 **LF**

## 覆盖策略

| 情形 | 处理 |
|------|------|
| 目标文件不存在 | 直接写 |
| 已存在同名 | 覆盖前告知用户；除非用户要求重生成 |
| 用户指定新文件名 | 从其指定 |

## 写入前终检

1. step 7 结构自检全过
2. step 8 去 AI 味已完成
3. 各版代码过样例，满分解过全部样例
4. 文件头 H1 为 `# 题目编号 题目名称`

## 交付回报

回报内容：

- 输出文件绝对路径
- 题目编号、题目名称、来源 URL
- 档位数 N 与各档可拿分
- 满分解核心算法与最优复杂度
- 若走了多题流程，附 `10-batch.md` 的汇总

## 清理

若无保留必要，删除中间文件 `{题目编号}_raw.md`、`{题目编号}_zh.md`（或按用户要求保留）。

## 完成

题解可直接用于课堂讲授或学生复习。
