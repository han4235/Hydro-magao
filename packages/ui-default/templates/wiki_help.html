    编译环境

    代码由 HydroJudge 评测。提交页默认选中的语言是 C++11（带 -O2），要交别的语言自己在下拉里换。

    各语言的编译参数与当前编译器版本都在状态页上。

    时间与内存限制

    时限与内存写在题目上，以题目为准：题目里写的时间就是该评测点的限时，评测机按进程实际占用的 CPU 时间计；内存按进程的虚拟内存与物理内存之和计。

    没写这两项的（比如理论卷）按 1 秒、256 MiB 计。

    输入输出

    除题面另有说明，一律从标准输入读、往标准输出写（stdin / stdout），不要自己读写文件。

    评测状态

    • Waiting 评测：评测请求正在等待被评测机抓取
    • Fetched 评测：评测请求已被评测机抓取，正在准备开始评测
    • Compiling 评测：正在编译中
    • Judging 评测：编译成功，正在评测中
    • Accepted 通过：程序输出完全正确
    • Wrong Answer 不通过：程序输出与标准答案不一致（不包括行末空格以及文件末空行）
    • Time Limit Exceeded 不通过：程序运行时间超过了题目限制
    • Memory Limit Exceeded 不通过：程序运行内存空间超过了题目限制
    • Runtime Error 不通过：程序运行时错误（如数组越界、被零除、运算溢出、栈溢出、无效指针等）
    • Compile Error 不通过：编译失败
    • System Error 错误：系统错误（如果您遇到此问题，请及时在讨论区进行反馈）
    • Canceled 其他：评测被取消
    • Unknown Error 其他：未知错误
    • Ignored 其他：被忽略
    有“成绩取消”字样则说明管理员手动标记此记录为取消，可能违反了服务条款，比如代码被发现与其他用户的代码十分相似。

    编译错误

    常见原因：递交时选错了语言；Java 的主类必须叫 Main；数组开得太大；以及一般的语法、类型错误。

    C/C++ 特别注意：

    • __int64 要写 long long。
    • main 的返回值必须是 int，不能写 void。
    • for (int i = 0; ...) 里的 i 出了这个循环就无效。
    • itoa 不是标准函数，用 snprintf 或 std::to_string 代替。

    课程训练

    「训练」把题目按课程和章节组织起来，从导航栏的「训练」进入，讲义、练习和提交记录都在同一页。

    有权限的老师可以在练习列表里加题、删题，拖动最左边的把手调整顺序。

    比赛规则

    赛制不同，递交与排名的规则也不同。

    • OI：以最后一次提交为准，务必避免编译错误；按总分排名，总分相同则并列。
    • IOI：可以多次提交，随时看得到自己的结果和排行榜；每道题按各子任务的最高分求和。
    • IOI(Strict)：比赛期间看不到自己的结果与排行榜，结束后才公布；计分方式同 IOI。
    • XCPC：按通过题数排名，同题数比总用时；每次错误提交加 20 分钟罚时。
    • Ledo：多次提交会扣分，排行榜取最高分，最终得分为 s × max(0.95^n, 0.7)，其中 s 是本次得分、n 是本次提交前的尝试次数。

    时间与空间限制以题目说明为准，见上面的时间与内存限制。

    通过率

    题库里显示的「通过率」是这道题的通过人数除以做过这道题的人数：同一个人交很多次也只算一次；还没有人提交过的题显示「—」。

    它只是参考，不影响成绩。

    等级分

    等级分由站点每天凌晨重新统计一次：做对题目会按题目难度加分，参加计入等级分的比赛会按名次升降。

    分数越高排名越靠前，「等级」按分数在站内的排名划分。刚交完题不会立刻变化，要等这次统计跑完才更新。

    题目难度

    题库里的「难度」是七个档位：入门、普及−、普及/提高−、普及+/提高、提高+/省选−、省选/NOI−、NOI/NOI+/CTSC，越靠后越难。难度在题目编辑页里设置，题库里没设置的显示「—」。

    题库可以按难度筛选，也可以按难度从低到高、从高到低排序。

    域与权限

    域是互相独立的空间：每个域有自己的题库、训练、讨论和比赛，你能看到什么、能做什么，由你在这个域里的角色与权限决定。

    本站默认的域是 system，打开首页就是它；别的域要用组织者给的入口地址进。域由站点管理员创建。

    测试数据配置

    有权限的人在题目页左侧的「文件」里上传测试数据（testdata）：文件名要与题目评测配置里引用的输入、输出文件名一致，大样例之类放在附加文件里。

    详细格式见配置文档。

    找回账号

    忘记密码或用户名，请联系老师或站点管理员；老师可以在「管理域 → 管理用户」里重置学生密码。

    Markdown

    题面、讲义和讨论区都支持 CommonMark 语法，另外扩展了这些写法：

    • Katex 语法的数学公式：行内 $E=mc^2$，独立成行的 $$E=mc^2$$。
    • 用 ==文字== 高亮。
    • 用 ![说明](url =100x100) 指定图片显示的大小。
    • 用 [^1] 写脚注。
    • 用 @[](/user/uid) 提及某个用户。
    • 用 @[video](https://.../a.mp4) 嵌入视频，@[bilibili](BV 号) 嵌入 B 站视频，@[pdf](...) 嵌入本站的 PDF 文件。
    • 在题目、比赛、作业、训练里，可以用 file://文件名 引用该页面附件中的文件。
    • 支持使用一部分 HTML 标签。
